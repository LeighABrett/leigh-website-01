# leigh-website-01

## Project Summary

Personal portfolio and landing page for Leigh Brett — product design leader. Currently a holding page while the full site is designed and built.

## Stack

- **Framework**: Next.js 16.1.6
- **Styling**: Tailwind CSS 4 + design tokens in `globals.css`
- **Animations**: Framer Motion 12
- **Language**: TypeScript
- **Hosting**: Vercel
- **Version Control**: GitHub (private repo)

## Brand

- **Typeface**: Inter (primary, variable font)
- **Colour palette**: Dark default (`#000000` bg, `#ffffff` fg), accent `#ee3800`
- **Light mode**: `#fafafa` bg, `#171717` fg
- **Tone**: Direct, confident, minimal. Let the work speak.
- **Logo**: Custom script "Leigh" wordmark (SVG, light and dark variants)
